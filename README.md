\# 🌙 夜刈 NIGHT REAP



單檔（single-file）割草生存網頁遊戲（Vampire Survivors-like）。

純 HTML＋JS＋Canvas，\*\*零依賴、零框架\*\*，手機／桌機皆可玩。



\## 🎮 玩法

\- 滑動搖桿／WASD 移動，武器全自動

\- 擊殺掉紫寶石＝經驗，升級三選一（最多 6 個技能家族，同家族可無限疊等）

\- 掉落道具：🧲 磁鐵（吸全場寶石）／🛡 護盾（擋一招）／❤️ 回血

\- 導演波次：蝠群、羊魔、精英魚人、🕸 織網者（蛛網減速）、☠ 審判者（十字极光）

\- \*\*3:00 Boss 羊魔王\*\*：骨彈環／衝鋒／召喚／骨盾無敵 phase

\- 結算可產出 1080×1080 成績卡，支援 Web Share 分享或下載



\## 🚀 執行

直接雙擊 `index.html`，或：

```bash

python -m http.server 8000   # 開 http://localhost:8000
